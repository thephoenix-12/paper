# Cultural Framing Index Headline Analysis Pipeline

## Project Overview

This project builds a reproducible Python pipeline for collecting, preprocessing, analysing, and visualising English-language news headlines from the UK, US, and Ireland. The project supports a dissertation on detecting cultural framing patterns in news headlines using interpretable stylometric features and a transparent Cultural Framing Index (CFI).

## Main Functions

The code can:

1. Collect headline data from GDELT.
2. Upload and process multiple CSV files.
3. Clean and standardise headline datasets.
4. Extract stylometric features using spaCy.
5. Calculate a Cultural Framing Index.
6. Compare CFI scores across the UK, US, and Ireland.
7. Generate summary tables and visualisations.
